## User Scenarios & Testing *(mandatory)*

### User Story 1 - 블로그 주인만 쓰는 관리 화면에 들어가기 (Priority: P1)

로그인한 블로그 주인이 사용자 메뉴에서 `블로그 관리`를 열면, 왼쪽에 메뉴가 있고 오른쪽에 내용이 보인다. 주인이 아닌 사람은 들어올 수 없다. 계정 설정(`마이페이지`)과 블로그 운영(`블로그 관리`)은 서로 다른 곳이다.

```
사용자 메뉴 → [블로그 관리] → 왼쪽 메뉴(대시보드·글 관리·분류 관리·댓글 관리·통계·설정)에서 고르기 → 오른쪽에 내용
```

**Why this priority**: 모든 운영 기능이 이 화면 안에 있다. 그리고 남의 블로그를 운영하지 못하게 막는 것이 가장 먼저다.

**Independent Test**: 주인 계정으로 `블로그 관리`를 열어 메뉴 여섯 개와 위쪽 버튼이 보이는지 확인한다. 로그아웃 상태와 다른 회원 계정으로는 들어갈 수 없는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 로그인한 블로그 주인일 때, **When** 사용자 메뉴에서 `블로그 관리`를 열면, **Then** 왼쪽에 `대시보드`, `글 관리`, `분류 관리`, `댓글 관리`, `통계`, `설정` 메뉴가 보이고, 메뉴 위에 블로그 이름과 "내 블로그 보기", "글쓰기" 버튼이 보이며, 오른쪽에 고른 메뉴의 내용이 보인다.
2. **Given** 로그인한 회원일 때, **When** 화면 위쪽 사용자 메뉴를 열면, **Then** 계정을 설정하는 `마이페이지`(CF-15)와 블로그를 운영하는 `블로그 관리`가 따로 있다.
3. **Given** 로그인하지 않았을 때, **When** 관리 화면을 열려고 하면, **Then** 로그인 창이 뜬다. (CF-16-1과 같다)
4. **Given** 다른 회원의 블로그일 때, **When** 로그인한 회원이 그 블로그의 관리 화면을 열려고 하면(화면을 거치지 않은 요청 포함), **Then** 관리 화면의 내용은 보이지 않는다.
5. **Given** 관리 화면을 보고 있을 때, **When** "내 블로그 보기"를 누르면, **Then** 방문자가 보는 내 블로그 화면으로 이동한다.

### User Story 2 - 글 관리: 비공개 글까지 내 글을 한곳에서 (Priority: P1)

블로그 주인이 비공개 글을 포함한 내 글 전체를 최신순으로 보고, 공개 여부와 분류로 걸러 보고, 글마다 보기·수정·삭제를 한다. 글을 쓰고 고치는 규칙은 글 기능(CF-05, CF-06)을 그대로 따른다.

**Why this priority**: 비공개 글까지 포함해 내 글을 한곳에서 찾고, 고치고, 지울 수 있어야 블로그를 운영할 수 있다.

**Independent Test**: 공개 글과 비공개 글을 섞어 11개 이상 쓴 뒤 글 관리를 열어, 모두 최신순으로 10개씩 나뉘어 보이는지, 거르기가 맞는지, 삭제 확인 뒤 글이 사라지는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 공개 글과 비공개 글을 합쳐 11개 이상 썼을 때, **When** 글 관리를 열면, **Then** 비공개 글을 포함한 내 글 전체가 최신순으로 한 페이지에 10개씩 나뉘어 보인다.
2. **Given** 글 목록이 보일 때, **When** 목록의 한 줄을 보면, **Then** 제목, 분류, 작성일, 공개 여부, 조회수, 댓글 수가 보인다.
3. **Given** 공개 글과 비공개 글, 여러 분류의 글이 있을 때, **When** 공개 여부(전체 / 공개 / 비공개)나 분류를 고르면, **Then** 그 조건에 맞는 글만 보인다.
4. **Given** 목록에 글이 있을 때, **When** 한 글의 `보기`를 누르면, **Then** 그 글이 보이고, `수정`을 누르면 글 수정 화면(CF-06)으로 이동한다.
5. **Given** 목록에 글이 있을 때, **When** 한 글의 `삭제`를 누르면, **Then** "삭제하면 되돌릴 수 없습니다. 삭제할까요?"로 확인하고, 확인하면 글이 지워져 목록에서 사라진다. 확인하지 않으면 지워지지 않는다.
6. **Given** 글 관리 화면일 때, **When** 목록 위의 글쓰기를 누르면, **Then** 바로 글쓰기 화면(CF-05)으로 이동한다.
7. **Given** 쓴 글이 하나도 없을 때, **When** 글 관리를 열면, **Then** "아직 쓴 글이 없습니다"와 글쓰기 버튼이 보인다. 거른 결과가 없으면 "글이 없습니다"가 보인다.

### User Story 3 - 분류 관리 (Priority: P2)

블로그 주인이 글을 나누는 분류를 추가하고, 이름을 바꾸고, 위·아래로 순서를 바꾸고, 지운다. 분류마다 이름과 글 개수, 구분용 색 점이 보인다. 이름 글자 수, 중복, 삭제 조건, "미분류" 규칙은 분류 기능(CF-07, CF-08)을 그대로 따른다.

**Why this priority**: 글을 정리하는 기능이라 글 관리가 갖춰진 뒤에 더한다.

**Independent Test**: 분류를 하나 추가하고, 이름을 바꾸고, 순서를 옮기고, 글이 있는 분류와 없는 분류를 각각 삭제해 본다.

**Acceptance Scenarios**:

1. **Given** 분류가 있을 때, **When** 분류 관리를 열면, **Then** 분류가 순서대로 보이고, 분류마다 이름, 글 개수, 구분용 색 점이 보이며, 목록 아래에 새 분류를 입력하는 칸이 있다.
2. **Given** 새 분류 이름을 입력했을 때, **When** 추가하면, **Then** 새 분류가 목록에 생기고 색은 정해진 순서로 저절로 정해진다. 색을 직접 고르는 칸은 없다.
3. **Given** 분류가 둘 이상 있을 때, **When** 한 분류의 이름을 바꾸거나 위·아래로 옮기면, **Then** 바꾼 이름과 순서가 목록에 반영된다.
4. **Given** 글이 하나도 없는 분류일 때, **When** 삭제하면, **Then** 그 분류가 지워진다.
5. **Given** 글이 하나라도 있는 분류일 때, **When** 삭제하려 하면, **Then** 지워지지 않는다.
6. **Given** 분류 관리 화면일 때, **When** 화면 아래를 보면, **Then** "글이 하나라도 있는 분류는 삭제할 수 없습니다. 글은 글 수정에서 다른 분류로 옮길 수 있습니다."가 항상 보인다.
7. **Given** 새 분류 이름이 비어 있을 때, **When** 추가하려 하면, **Then** "분류 이름을 입력해 주세요"가 보인다.

### User Story 4 - 댓글 관리 (Priority: P2)

블로그 주인이 내 블로그 글에 달린 모든 댓글을 최신순으로 보고, 어느 글에 달린 댓글인지 확인하고, 필요하면 지운다. 댓글 규칙은 댓글 기능(CF-18)을 그대로 따른다.

**Why this priority**: 방문자와 소통하는 곳이다. 글 관리가 갖춰진 뒤에 더한다.

**Independent Test**: 여러 글에 댓글을 단 뒤 댓글 관리를 열어 최신순으로 보이는지, 글 제목을 누르면 그 글의 댓글 위치로 가는지, 삭제 확인 뒤 지워지는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 내 블로그 여러 글에 댓글이 달려 있을 때, **When** 댓글 관리를 열면, **Then** 내 블로그 글에 달린 모든 댓글이 최신순(새 댓글이 위)으로 한 페이지에 10개씩 나뉘어 보인다.
2. **Given** 댓글 목록이 보일 때, **When** 한 댓글을 보면, **Then** 작성자 닉네임, 작성 시각, 내용 앞 50자, 댓글이 달린 글 제목이 보인다.
3. **Given** 댓글 목록이 보일 때, **When** 댓글 아래의 글 제목을 누르면, **Then** 그 글의 댓글 위치로 이동한다.
4. **Given** 이미 탈퇴한 사람이 쓴 댓글일 때, **When** 목록에서 보면, **Then** 작성자가 "탈퇴한 사용자"로 보인다. (CF-18-6)
5. **Given** 내 글에 달린 댓글이 있을 때, **When** 누가 쓴 댓글이든 `삭제`를 누르면, **Then** "댓글을 삭제할까요?"로 확인하고, 확인하면 지워진다. (CF-18-4)
6. **Given** 내 글에 달린 댓글이 하나도 없을 때, **When** 댓글 관리를 열면, **Then** "아직 달린 댓글이 없습니다"가 보인다.

### User Story 5 - 새 댓글 표시 (Priority: P2)

내 글에 새 댓글이 달리면 메뉴, 사용자 메뉴, 대시보드에 숫자가 보이고, 댓글 목록에서는 그 댓글에 `NEW`가 붙는다. 댓글 관리를 열면 모두 읽은 것으로 바뀌어 숫자와 `NEW`가 사라진다. 알림은 숫자와 `NEW`까지만 한다.

```
내 글에 새 댓글 → 메뉴 옆·사용자 메뉴·대시보드에 숫자 → [댓글 관리] 열기 → 읽음 처리(숫자와 NEW 사라짐)
```

**Why this priority**: 새 댓글을 놓치지 않게 해 주는 기능이다. 댓글 관리가 있어야 뜻이 있으므로 그 뒤에 더한다.

**Independent Test**: 다른 회원 계정으로 내 글에 댓글을 두 개 달고, 숫자 2가 세 곳에 보이는지, 댓글 관리를 열면 사라지는지 확인한다. 내 계정으로 단 댓글은 세지 않는지도 확인한다.

**Acceptance Scenarios**:

1. **Given** 내가 마지막으로 댓글 관리를 연 뒤 다른 사람이 내 글에 댓글 2개를 달았을 때, **When** 관리 화면을 보면, **Then** ① 왼쪽 메뉴 `댓글 관리` 옆, ② 화면 위쪽 사용자 메뉴, ③ 대시보드에 숫자 2가 보인다.
2. **Given** 새 댓글이 있을 때, **When** 댓글 관리 목록을 보면, **Then** 새 댓글에만 `NEW`가 붙어 있다.
3. **Given** 내가 내 글에 댓글을 썼을 때, **When** 새 댓글 수를 보면, **Then** 내가 쓴 댓글은 세지 않는다.
4. **Given** 새 댓글이 있을 때, **When** 댓글 관리 화면을 열면, **Then** 새 댓글이 모두 "읽음"이 되어 숫자와 `NEW`가 사라진다.
5. **Given** 읽음 처리를 마친 뒤 새 댓글이 하나 더 달렸을 때, **When** 관리 화면을 보면, **Then** 그 사이에 달린 댓글만 새 댓글로 세어 숫자 1이 보인다.
6. **Given** 새 댓글이 있을 때, **When** 알림을 살펴보면, **Then** 숫자와 `NEW` 표시만 있고, 종 모양 알림 목록, 메일, 푸시 알림은 오지 않는다.

### User Story 6 - 통계: 조회수와 방문자 보기 (Priority: P2)

방문자가 글을 열면 조회수와 방문자 수가 쌓이고, 블로그 주인은 통계 화면에서 7일 또는 30일의 일별 조회수·방문자·댓글 수를 그래프로 본다. 글마다 누적 조회수도 따로 센다.

**Why this priority**: 내 블로그가 얼마나 읽히는지 알게 해 준다. 글 관리의 조회수와 대시보드의 숫자가 이 기능에서 나오므로 대시보드보다 먼저 한다.

**Independent Test**: 다른 사람 계정으로 글을 여러 번 열어 본 뒤, 통계 화면에서 조회수와 방문자 숫자가 규칙대로 쌓였는지, 기간을 바꾸면 그래프가 바뀌는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 통계 화면을 처음 열 때, **When** 화면이 뜨면, **Then** 기간은 30일로 골라져 있고, 7일 / 30일 중에서 고를 수 있다.
2. **Given** 통계 화면이 30일일 때, **When** 7일을 고르면, **Then** 최근 7일의 일별 숫자로 바뀐다.
3. **Given** 며칠 동안 방문 기록이 쌓였을 때, **When** 통계 화면을 보면, **Then** 일별 조회수와 방문자는 한 그래프에, 일별 댓글 수는 다른 그래프에 보이고, 그래프에 마우스를 올리면 그날의 숫자가 보인다.
4. **Given** 어떤 사람이 내 글을 한 번 열었을 때, **When** 같은 글을 30분 안에 다시 열면, **Then** 조회수는 늘지 않는다. 30분이 지난 뒤에 다시 열면 다시 센다.
5. **Given** 로그인하지 않은 방문자일 때, **When** 내 글을 열면, **Then** 조회수에 센다.
6. **Given** 한 사람이 같은 날 내 블로그에서 글 3개를 열었을 때, **When** 그날의 숫자를 보면, **Then** 방문자는 1, 조회수는 3이다.
7. **Given** 같은 사람이 한국 시간 23시 59분과 그다음 날 0시 1분에 내 블로그를 열었을 때, **When** 일별 숫자를 보면, **Then** 서로 다른 날의 방문자로 각각 센다.
8. **Given** 글이 여러 개일 때, **When** 글 관리 목록과 대시보드의 인기 글을 보면, **Then** 글마다 따로 센 누적 조회수가 보인다.
9. **Given** 통계 화면일 때, **When** 화면을 살펴보면, **Then** 어디서 들어왔는지(유입 경로), 시간대별, 기기별 분석은 없다.

### User Story 7 - 대시보드 (Priority: P3)

블로그 주인이 관리 화면을 열면 오늘·어제·누적 숫자, 최근 30일 그래프, 인기 글, 최근 글, 새 댓글을 한 화면에서 본다.

**Why this priority**: 다른 기능이 만든 숫자와 목록을 한곳에 모아 보여 주는 요약판이다. 각 기능이 갖춰진 뒤에 더한다.

**Independent Test**: 글과 댓글, 방문 기록이 있는 블로그의 대시보드를 열어 숫자와 목록이 맞는지 확인한다. 새 블로그로도 열어 빈 상태를 확인한다.

**Acceptance Scenarios**:

1. **Given** 방문 기록과 댓글이 쌓였을 때, **When** 대시보드를 열면, **Then** 오늘·어제·누적 조회수, 오늘·어제·누적 방문자, 새 댓글 수가 한눈에 보인다.
2. **Given** 대시보드일 때, **When** 그래프를 보면, **Then** 최근 30일의 일별 조회수와 방문자가 선 그래프로 보인다. "통계 더 보기"를 누르면 통계 화면으로 이동한다.
3. **Given** 공개 글과 비공개 글이 있을 때, **When** 인기 글을 보면, **Then** 최근 7일 동안 조회수가 많은 공개 글 5개가 제목과 조회수와 함께 보이고, 비공개 글은 나오지 않는다.
4. **Given** 글이 6개 이상 있을 때, **When** 최근 글을 보면, **Then** 최근에 쓴 글 5개가 작성일과 함께 보이고, 비공개 글에는 "비공개" 표시가 붙는다.
5. **Given** 새 댓글이 있을 때, **When** 대시보드를 보면, **Then** 새 댓글 숫자가 강조되어 보이고, "댓글 보기"를 누르면 댓글 관리로 이동한다.
6. **Given** 글도 댓글도 없을 때, **When** 대시보드를 열면, **Then** 숫자는 0으로 보이고 인기 글과 최근 글 목록에는 안내 문구("아직 쓴 글이 없습니다")가 보인다.

### User Story 8 - 블로그 설정 (Priority: P3)

블로그 주인이 블로그 이름과 소개를 바꾸고 저장한다. 이름·소개 규칙은 블로그 기능(CF-04)을 그대로 따른다.

**Why this priority**: 작은 기능이고, 없어도 블로그를 운영할 수 있다.

**Independent Test**: 설정에서 블로그 이름과 소개를 바꿔 저장하고, 다른 화면에서 새 이름이 보이는지 확인한다. 이름을 비우고 저장해 본다.

**Acceptance Scenarios**:

1. **Given** 설정 화면일 때, **When** 화면을 보면, **Then** 블로그 이름(필수, 1~30자)과 소개(0~200자)를 바꾸는 칸이 있고, 소개 아래에 "n/200"으로 글자 수가 보인다.
2. **Given** 규칙에 맞는 이름과 소개를 입력했을 때, **When** 저장하면, **Then** "저장했습니다"가 보이고 모든 화면에 바뀐 이름과 소개가 바로 보인다.
3. **Given** 블로그 이름을 비웠을 때, **When** 저장하려 하면, **Then** "블로그 이름을 입력해 주세요"가 칸 아래에 보이고 저장되지 않는다.
4. **Given** 설정 화면일 때, **When** 화면을 살펴보면, **Then** "데모 데이터 초기화" 버튼은 없다.

---

### Edge Cases

- 글도 댓글도 없는 **새 블로그**를 열면? → 대시보드 숫자는 0, 글 관리는 "아직 쓴 글이 없습니다"와 글쓰기 버튼, 댓글 관리는 "아직 달린 댓글이 없습니다"를 보여 준다. (BM-02-6, BM-03-6, BM-05-8)
- 글 관리에서 **거른 결과가 없으면?** → "글이 없습니다"를 보여 준다.
- 공개 여부와 분류를 **함께 고르면?** → 두 조건에 모두 맞는 글만 보여 준다.
- **글이 있는 분류를 지우려 하면?** → 지워지지 않고, 글은 글 수정에서 다른 분류로 옮길 수 있다고 안내한다.
- **분류 이름이나 블로그 이름이 비어 있으면?** → "분류 이름을 입력해 주세요", "블로그 이름을 입력해 주세요"를 칸 아래에 보여 준다.
- 블로그 이름이 30자를, 소개가 200자를 **넘으면?** → 이름·소개 규칙(CF-04)에 맞지 않으므로 저장하지 않는다.
- 글이나 댓글 삭제 확인에서 **취소하면?** → 지워지지 않는다.
- **내가 내 글에 쓴 댓글**은? → 새 댓글로 세지 않는다.
- 댓글 관리를 **다시 열면?** → 마지막으로 연 뒤에 달린 댓글만 새 댓글로 센다.
- **탈퇴한 사람이 쓴 댓글**은? → 작성자를 "탈퇴한 사용자"로 보여 준다.
- 같은 사람이 같은 글을 **30분 안에 다시 열면?** → 조회수에 세지 않는다. 로그인하지 않은 방문자도 같다.
- 한 사람이 **하루에 글 3개**를 열면? → 방문자는 1, 조회수는 3이다.
- **한국 시간 자정**이 지나면? → 날짜가 바뀌어 새 날의 숫자로 센다.
- **다른 회원의 관리 화면**을 열려 하면? → 볼 수 없다. 화면을 거치지 않은 요청도 같다.

## Requirements *(mandatory)*

### Functional Requirements

**전체 구성과 접근** (BM-01)

- **FR-001**: 블로그 관리 화면은 왼쪽에 메뉴, 오른쪽에 내용을 보여 준다. 메뉴는 `대시보드`, `글 관리`, `분류 관리`, `댓글 관리`, `통계`, `설정`이다. 메뉴 위에는 블로그 이름, "내 블로그 보기", "글쓰기" 버튼을 둔다. (BM-01-1)
- **FR-002**: 관리 화면은 로그인한 블로그 주인만 볼 수 있다. 로그인하지 않았으면 로그인 창을 띄우고(CF-16-1과 같다), 다른 회원의 관리 화면은 볼 수 없다. (BM-01-2)
- **FR-003**: FR-002의 접근 규칙은 화면 검사와 상관없이, 화면을 거치지 않은 요청에도 똑같이 적용한다. (BM-01-2, NF-02의 취지)
- **FR-004**: 계정 설정은 마이페이지(CF-15)에서, 블로그 운영은 이 화면에서 한다. 로그인 후 사용자 메뉴에는 두 항목이 따로 있다. (BM-01-3)
- **FR-005**: "내 블로그 보기"를 누르면 방문자가 보는 내 블로그 화면으로 이동한다. (BM-01-4)

**대시보드** (BM-02)

- **FR-006**: 오늘·어제·누적 조회수, 오늘·어제·누적 방문자, 새 댓글 수를 한눈에 보여 준다. (BM-02-1)
- **FR-007**: 최근 30일의 일별 조회수와 방문자를 선 그래프로 보여 준다. "통계 더 보기"를 누르면 통계 화면으로 간다. (BM-02-2)
- **FR-008**: 최근 7일 동안 조회수가 많은 공개 글 5개를 제목과 조회수로 보여 준다. (BM-02-3)
- **FR-009**: 최근에 쓴 글 5개를 작성일과 함께 보여 준다. 비공개 글에는 "비공개" 표시를 붙인다. (BM-02-4)
- **FR-010**: 새 댓글이 있으면 숫자를 강조해서 보여 주고, "댓글 보기"로 댓글 관리에 연결한다. (BM-02-5)
- **FR-011**: 글이나 댓글이 없으면 숫자는 0으로, 목록은 안내 문구로 보여 준다. (BM-02-6)

**글 관리** (BM-03) — 글을 쓰고 고치는 규칙은 CF-05, CF-06을 따른다

- **FR-012**: 비공개 글을 포함한 내 글 전체를 최신순으로 보여 준다. 한 페이지에 10개씩 나눠 본다. (BM-03-1)
- **FR-013**: 목록에는 제목, 분류, 작성일, 공개 여부, 조회수, 댓글 수를 보여 준다. (BM-03-2)
- **FR-014**: 공개 여부(전체 / 공개 / 비공개)와 분류로 걸러 볼 수 있다. (BM-03-3)
- **FR-015**: 글마다 보기, 수정, 삭제를 할 수 있다. 수정은 글 수정 화면(CF-06)으로 간다. 삭제는 "삭제하면 되돌릴 수 없습니다. 삭제할까요?"로 확인한 뒤 지운다. (BM-03-4)
- **FR-016**: 목록 위에서 바로 글쓰기 화면(CF-05)으로 갈 수 있다. (BM-03-5)
- **FR-017**: 쓴 글이 없으면 "아직 쓴 글이 없습니다"와 글쓰기 버튼을, 거른 결과가 없으면 "글이 없습니다"를 보여 준다. (BM-03-6)

**분류 관리** (BM-04) — 분류 규칙은 CF-07, CF-08을 그대로 따른다

- **FR-018**: 분류 목록을 순서대로 보여 주고, 분류마다 이름과 글 개수를 적는다. 목록 아래에 새 분류 입력칸이 있다. (BM-04-1)
- **FR-019**: 추가, 이름 변경, 위·아래 순서 바꾸기, 삭제를 이 화면에서 한다. 이름 글자 수, 중복, 삭제 조건, "미분류" 규칙은 CF-08-2 ~ 8을 따른다. (BM-04-2)
- **FR-020**: 분류마다 구분용 색 점을 보여 준다. 새 분류의 색은 정해진 순서로 자동 배정하고, 직접 고르게 하지는 않는다. (BM-04-3)
- **FR-021**: 화면 아래에 "글이 하나라도 있는 분류는 삭제할 수 없습니다. 글은 글 수정에서 다른 분류로 옮길 수 있습니다."를 항상 적어 둔다. (BM-04-4)
- **FR-022**: 분류 이름이 비어 있으면 "분류 이름을 입력해 주세요"를 보여 준다. (BM-04-2, 안내 문구 표)

**댓글 관리** (BM-05) — 댓글 규칙은 CF-18을 따른다

- **FR-023**: 내 블로그 글에 달린 모든 댓글을 최신순으로 보여 주고, 한 페이지에 10개씩 나눠 본다. 글 상세 화면은 오래된 댓글이 위이지만, 이 화면은 새 댓글을 먼저 보려는 곳이라 반대이다. (BM-05-1)
- **FR-024**: 작성자 닉네임, 작성 시각, 내용 앞 50자, 댓글이 달린 글 제목을 보여 준다. 글 제목을 누르면 그 글의 댓글 위치로 이동한다. 탈퇴한 작성자는 "탈퇴한 사용자"로 보여 준다(CF-18-6). (BM-05-2)
- **FR-025**: 블로그 주인은 내 글에 달린 모든 댓글을 지울 수 있다. "댓글을 삭제할까요?"로 확인한 뒤 지운다(CF-18-4). (BM-05-3)
- **FR-026**: 댓글이 없으면 "아직 달린 댓글이 없습니다"를 보여 준다. (BM-05-8)

**새 댓글 표시** (BM-05)

- **FR-027**: 마지막으로 댓글 관리를 연 뒤 달린 댓글을 "새 댓글"로 센다. 내가 쓴 댓글은 세지 않는다. (BM-05-4)
- **FR-028**: 새 댓글이 있으면 ① 왼쪽 메뉴 `댓글 관리` 옆, ② 화면 위쪽 사용자 메뉴, ③ 대시보드에 숫자를 보여 주고, 댓글 목록에서는 해당 댓글에 `NEW`를 붙인다. (BM-05-5)
- **FR-029**: 댓글 관리 화면을 열면 새 댓글이 모두 "읽음"이 되어 숫자와 `NEW`가 사라진다. (BM-05-6)
- **FR-030**: 종 모양 알림 목록, 메일, 푸시 알림은 만들지 않는다. 숫자와 `NEW` 표시까지만 한다. (BM-05-7)

**통계** (BM-06)

- **FR-031**: 통계 기간은 7일 / 30일 중에서 고른다. 처음에는 30일이다. (BM-06-1)
- **FR-032**: 일별 조회수와 방문자를 한 그래프에, 일별 댓글 수를 다른 그래프에 보여 준다. 그래프에 마우스를 올리면 그날의 숫자가 보인다. (BM-06-2)
- **FR-033**: 조회수는 글 상세를 열 때 센다. 같은 사람이 같은 글을 30분 안에 다시 열면 세지 않는다. 로그인하지 않은 방문자도 센다. (BM-06-3)
- **FR-034**: 방문자는 내 블로그를 찾아온 사람 수이다. 같은 사람은 하루에 한 번만 센다. (BM-06-4)
- **FR-035**: 한 사람이 하루에 글 3개를 열면 방문자는 1, 조회수는 3이다. 조회수와 방문자는 따로 센다. (BM-06-5)
- **FR-036**: 날짜는 한국 시간 자정에 바뀐다. (BM-06-6)
- **FR-037**: 글마다 누적 조회수를 따로 센다. 글 관리 목록의 조회수와 대시보드의 인기 글에 쓴다. (BM-06-7)
- **FR-038**: 어디서 들어왔는지(유입 경로), 시간대별·기기별 분석은 이번 범위에서 만들지 않는다. (BM-06-8)

**블로그 설정** (BM-07) — 이름·소개 규칙은 CF-04를 따른다

- **FR-039**: 블로그 이름(필수, 1~30자)과 소개(0~200자)를 바꾼다. 소개 아래에 "n/200"으로 글자 수를 보여 준다. (BM-07-1)
- **FR-040**: 저장하면 "저장했습니다"를 보여 주고 모든 화면에 바로 반영한다. 이름이 비어 있으면 "블로그 이름을 입력해 주세요"를 칸 아래에 보여 준다. (BM-07-2)
- **FR-041**: 시안(데모)에 있는 "데모 데이터 초기화" 버튼은 시안을 되돌리려는 것이므로, 실제 서비스에는 만들지 않는다. (BM-07-3)

**분류 공개 여부 (2026-10-07 추가)**

- **FR-042**: 분류 관리에서 분류마다 **공개 / 비공개**를 바꿀 수 있고, 비공개 분류에는 "비공개" 표시를 붙인다. 공개 여부의 규칙은 `003`의 CF-08-10을 따른다. 분류 관리의 글 개수는 블로그 주인 기준(비공개 글 포함)으로 센다. (CF-08-10)

### Key Entities *(include if feature involves data)*

- **블로그**: 회원 한 명이 가진 블로그. 이름(1~30자)과 소개(0~200자)를 가지며, 이 명세의 관리 화면이 다루는 대상이다. 주인만 관리 화면을 쓸 수 있다.
- **글**: 블로그 안의 글. 이 명세에서는 제목, 분류, 작성일, 공개 여부, 누적 조회수, 댓글 수를 목록에 보여 준다. 글 자체의 규칙은 글 기능(003)에서 다룬다.
- **분류**: 한 블로그 안에서 글을 나누는 분류. 이름, 순서, 구분용 색, 글 개수를 가진다.
- **댓글**: 글에 달린 댓글. 작성자, 작성 시각, 내용, 달린 글을 가진다. 블로그 주인이 마지막으로 댓글 관리를 연 시각보다 늦게 달리고 내가 쓰지 않은 댓글이 "새 댓글"이다. 댓글 자체의 규칙은 댓글 기능(005)에서 다룬다.
- **일별 통계**: 블로그의 하루(한국 시간 기준) 숫자. 그날의 조회수, 방문자 수, 댓글 수를 가지며, 대시보드와 통계 화면의 그래프가 이것을 읽는다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 블로그 주인이 아닌 사람(로그인하지 않은 사람 포함)이 관리 화면의 내용을 볼 수 있는 경우는 0건이다. 화면을 거치지 않은 요청도 모두 거절된다.
- **SC-002**: 글 관리 목록에서 내 글(공개·비공개 모두)이 빠지는 경우는 0건이고, 항상 최신순으로 한 페이지에 10개씩 보인다.
- **SC-003**: 글과 댓글은 확인 문구에 동의한 뒤에만 지워진다. 확인 없이 지워지는 경우는 0건이다.
- **SC-004**: 글이 하나라도 있는 분류가 삭제되는 경우는 0건이다.
- **SC-005**: 같은 사람이 같은 글을 30분 안에 다시 열어도 그 글의 조회수는 늘지 않는다. 로그인하지 않은 방문자도 같다.
- **SC-006**: 한 사람이 같은 날 글 3개를 열면 그날 방문자는 정확히 1, 조회수는 정확히 3이다.
- **SC-007**: 한국 시간 자정 전후의 방문은 서로 다른 날로 센다. 하루 기준이 어긋난 경우는 0건이다.
- **SC-008**: 새 댓글 숫자는 세 곳(메뉴 옆, 사용자 메뉴, 대시보드)에서 항상 같은 값이다. 댓글 관리를 한 번 열면 세 곳 모두 숫자가 사라지고, 내가 쓴 댓글이 새 댓글에 포함되는 경우는 0건이다.
- **SC-009**: 대시보드의 인기 글에 비공개 글이 나오는 경우는 0건이고, 최근 7일 조회수가 많은 공개 글이 5개까지 보인다.
- **SC-010**: 블로그 이름이나 소개를 저장한 직후, 모든 화면에서 이전 이름이나 소개가 보이는 경우는 0건이다.
- **SC-011**: 블로그 주인이 `블로그 관리`를 열어 대시보드에서 어제 방문자 수와 새 댓글 수를 확인하는 데 1분 안에 끝낸다. (제안값)

## Assumptions

- 이 명세의 원본 `docs/2-요구사항/상세/06-블로그관리-통계.md`는 **초안**이다. `요구사항-공통.md`에 없던 내용을 UI 시안과 대화에서 처음 문서로 옮긴 것이고, ID는 `BM-xx`(블로그 관리)로 새로 붙였다. 원본이 바뀌면 이 명세도 함께 고친다.
- 원본에서 `확인 필요`로 표시된 **BM-01-3, BM-05-7, BM-06-5, BM-06-8**은 팀과 아직 합의하지 않았다. 이 명세는 원본에 적힌 현재 내용(FR-004, FR-030, FR-035, FR-038)을 따르고, 합의가 달라지면 그 FR을 먼저 고친다.
- 의존하는 기능: 로그인과 회원은 001, 글과 분류는 003, 댓글은 005에 기댄다. 마이페이지(CF-15)는 002에서 다룬다.
- 권한: 이 화면은 로그인한 **블로그 주인만** 쓸 수 있다. 권한표(누가 무엇을 할 수 있는가)는 각 기능의 명세에서 정하고, 이 명세는 "로그인한 블로그 주인인가"까지만 다룬다.
- 글을 쓰고 고치는 규칙(CF-05, CF-06), 분류 규칙(CF-07, CF-08), 댓글 규칙(CF-18), 블로그 이름·소개 규칙(CF-04)은 해당 기능의 명세를 그대로 따르며, 이 명세에서 다시 정하지 않는다.
- 용어: 이 명세의 "분류"(카테고리)는 한 블로그 안에서 주인이 만드는 분류이다. "주제"는 글마다 고르는 서비스 전체의 분류로 다르다(2026-10-07 변경). 분류 공개 여부(FR-042)는 2026-10-07에 `003`(CF-08-10)과 함께 더했다. 설정 화면에서는 블로그 이름과 소개만 바꾼다(BM-07-1).
- 화면에 보여 줄 문구와 숫자(글자 수, 시간, 횟수, 기간)는 원본의 `안내 문구`, `기본값` 표를 따르며, 바꿀 수 있어야 한다.
- 원본 요구사항 ID 중 연결하지 못한 것은 없다. 묶음 ID(BM-01 ~ BM-07)는 FR 묶음 제목에, 다른 문서의 규칙 ID(CF-04 등)와 NF-02는 해당 FR과 User Story에 표시했다.
- **이 명세에서 해석한 것** (원본에 직접 적혀 있지 않은 부분):
  - 댓글 관리도 한 페이지에 10개씩 나눠 본다. BM-05-1 요구사항에는 없지만 `기본값` 표에 "글 관리·댓글 관리 한 페이지 10개"로 적혀 있다.
  - 글 관리에서 공개 여부와 분류를 함께 고르면 두 조건에 모두 맞는 글만 보인다.

  - 같은 글을 30분이 지난 뒤에 다시 열면 다시 센다. (`조회수 중복 제외 시간 30분`의 반대쪽)
