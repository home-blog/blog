# AIGJ 블로그 프로젝트 문서

> 티스토리 같은 블로그를 **기획부터 설계, 배포까지** 만들어 보는 프로젝트의 문서 모음입니다. (이름은 임시로 MyBlog)
> 여러 사람이 각자 블로그를 운영하고, 방문자는 한곳에서 둘러보는 멀티 블로그 서비스를 목표로 합니다.

문서는 **2026-10-02 기준**이고, 기술 내용은 가안이 많습니다. 확정 여부는 각 문서의 상태 표기(`확정` / `가안` / `미정`)를 따릅니다.

## 진행 단계

① 요구사항 정리 (진행 중) → ② 기술 스택 (가안) → ③ 시스템 아키텍처 → ④ ERD → ⑤ API 명세서 → ⑥ 구현

## 문서 지도

### 요구사항

| 문서 | 내용 |
|---|---|

| [요구사항-비교표](docs/요구사항-비교표.md) | 팀원 4명의 요구사항 문서를 기능별로 비교한 표 |

각 파일은 `쉬운 설명 → 요구사항 → 구현 방식` 순서입니다. 읽는 법과 ID 규칙은 [상세/00-목차](docs/상세/00-목차.md)를 봅니다.

|---|---|

| [02-계정관리](docs/상세/02-계정관리.md) | 마이페이지, 내 정보 수정, 비밀번호 변경, 회원 탈퇴 |

| [06-블로그관리-통계](docs/상세/06-블로그관리-통계.md) | 대시보드, 글·분류·댓글 관리, 통계 (초안) |

## 읽는 순서

1. 처음이라면 [요구사항-공통](docs/요구사항-공통.md)과 [요구사항-비교표](docs/요구사항-비교표.md)로 팀의 공통 범위를 봅니다.
2. 기능별 규칙은 [상세/00-목차](docs/상세/00-목차.md)에서 필요한 파일을 고릅니다. 각 파일의 `쉬운 설명`부터 읽으면 됩니다.
3. 낯선 기술 용어는 [가이드 목차](docs/가이드/00-목차.md)에서 찾습니다.

## 작성 규칙

- 요구사항 문서에는 **"무엇을 할 수 있어야 하는가"만** 적습니다. 기술은 `상세`의 `구현 방식`과 `기술스택-아키텍처`에만 적습니다.
- 정해지지 않은 항목은 임의로 정하지 않고, 선택지와 추천안을 함께 적습니다.
