여러 사람이 각자 블로그를 쓰고 한곳에서 둘러보는 멀티 블로그 서비스 *글결* 의 서버 API입니다 (릴리스 {release}).

이 문서의 요청과 응답은 *테스트가 실제로 보내고 받은 것* 입니다 (Spring REST Docs, `ApiDocumentationTest`).
응답에 문서에 없는 칸이 생기거나 적은 칸이 사라지면 테스트가 실패하므로, 문서가 코드와 어긋나지 않습니다.
전체 API 목록(85개)은 개발 서버의 Swagger 화면(`/swagger-ui.html`)에 있고, 이 문서는 주요 흐름을 예시와 함께 설명합니다.

[[overview]]
== 공통 약속

=== 주소와 버전
모든 주소는 `/api/v1/…` 입니다. API 버전은 릴리스 번호와 따로 가서, 칸을 더하는 변경은 v1 그대로 두고 칸을 빼거나 뜻을 바꿀 때만 v2를 엽니다.

=== 로그인 (서버 세션)
로그인하면 세션 쿠키 `SESSION` 이 생기고, 세션은 PostgreSQL에 저장합니다 (JWT를 쓰지 않습니다).
정한 시간(`auth.session.idle-timeout`) 동안 쓰지 않으면 끝납니다. 로그인이 필요한 API를 로그인 없이 부르면 `401` 입니다.

=== CSRF
GET이 아닌 요청은 쿠키 `XSRF-TOKEN` 의 값을 머리글 `X-XSRF-TOKEN` 에 실어 보냅니다.
토큰은 <<auth-csrf>> 로 받고, 로그인하면 바뀌므로 로그인한 뒤 다시 받습니다.

=== 오류
모든 오류는 같은 모양입니다. 볼 권한이 없는 글·댓글·이미지는 있는지조차 알 수 없도록 없는 것과 같은 `404` 로 답합니다.

[cols="1,3"]
|===
| 상태 | 뜻

| `400` | 입력값이 규칙에 맞지 않음 (`fieldErrors` 에 칸마다 까닭)
| `401` | 로그인이 필요함
| `403` | CSRF 토큰이 없거나 틀림, 또는 할 수 없는 일
| `404` | 없거나 볼 수 없음
| `409` | 이미 있음 (예: 같은 이름의 분류)
| `429` | 너무 자주 보냄 (`retryAfterSeconds` 뒤에 다시)
|===

[[notice]]
== 공지사항
업데이트 소식과 공지입니다. 읽기는 누구나, 쓰기·고치기·지우기는 **관리자**만 합니다(관리자가 아니면 `403`).

[[writing]]
== 글쓰기 도구
글쓰기 잔디, 연재, 임시 저장, 예약 발행입니다. 임시 저장·예약 글은 주인만 보고, 글 목록·검색·첫 화면 어디에도 나오지 않습니다.

[[writing-activity]]

operation::writing-activity[snippets='path-parameters,http-request,http-response,response-fields']

operation::series-create[snippets='request-headers,request-fields,http-request,http-response,response-fields']

[[post-series]]

operation::post-series[snippets='path-parameters,http-request,http-response,response-fields']

operation::draft-schedule[snippets='path-parameters,request-headers,request-fields,http-request,http-response,response-fields']
